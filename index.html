Shimmer — Character Generation Prototype (v0)

Validates the ability → Vocation → Confluence Board generation logic from character_system_design.md. Scope is deliberately narrow: one hardcoded Potential pair, a single triangular board, no Vestiges/items, no FTL meta-map. See the "Edit here" block in the JS source to change Aspects, Potentials, or word banks — no build step, just edit and reload.
Potentials: (hardcoded for v0 — Step 1 of the real flow is a picker, not built here)

1. Craft Abilities (0/8)

Pick an Aspect below (each of the 8 can only be used once — used ones stay visible, crossed out).

2. Generated Vocations

Each ability grants 1 base Vocation for its Aspect. Every other ability sharing that ability's Category adds +1 bonus Vocation for that Aspect — watch the whole Category flash when that happens. Hover an ability card to see which Vocation rows it produced.

3. Confluence Board (simplified)

Select a Vocation, then place it on the pulsing node — boards fill in order, like a snaking path, not anywhere you like. Connected nodes get a line. Real multi-board connectivity/rotation/Rune Words are still out of scope for v0.
